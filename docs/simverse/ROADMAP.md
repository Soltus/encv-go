# SimVerse 下一阶段开发计划（P9+，借鉴 2024 年后手游）

> 本文档为 **前瞻性路线图**，承接 `README.md` 的 P0–P8 完成情况。
> 调研基线：2024 年及以后上线的代表性手游及其被验证的玩法/系统。
> 说明：本沙箱环境无法访问外网，下列游戏特征基于公开已知信息（发行时间、核心系统）整理，
> 落地前建议以各产品最新版本与官方资料二次校准。

**共性结论（2024+ 手游的设计共识）**：
1. **世界要"活"**：NPC 有作息/日常，区域有动态事件，玩家能感知"此刻正在发生什么"。
2. **关系要"深"**：好感/羁绊是留存核心，AI 伴侣把"角色"变成"陪伴"。
3. **经济要"由玩家驱动"**：模拟物价是底色，玩家交易/拍卖行才是活跃度引擎。
4. **组织要"可战"**：公会/阵营/领地战把单机模拟变成社交场。
5. **长线要"有赛季"**：Battle Pass + 限时活动 + 跨端，保证持续回流。
6. **共创要"可分享"**：UGC 叙事 + 拍照分享，降低内容生产成本、放大传播。

### 1.1 卡片手游补充：流派系统与 UI 设计（龙息：神寂 / 潮汐守望者 等）

**代表性特征**
- **龙息：神寂（Dragonheir: Silent Gods）**：开放世界战棋 RPG，强调"同一角色多重流派"——通过天赋、装备、符文组合出 输出 / 坦克 / 辅助 等不同 build；并有元素共鸣。其价值在于把"一个角色"变成"多种可辨识定位"。
- **潮汐守望者**（及同类卡牌 / 自走棋：云顶之弈、炉石传说）：核心是 **流派协同 / 羁绊**——2 / 4 / 6 个同阵营·同职业单位触发递增加成；配套 **卡牌收集 + 编队 + 抽卡** 的完整 UI 范式。
- **可归纳的通用范式**：
  1. **流派（Build / Archetype）**：同一底子经不同"天赋 + 装备 + 符文"长出不同玩法定位。
  2. **协同 / 羁绊（Synergy）**：同标签（元素 / 职业 / 阵营）数量达到阈值即触发加成，鼓励"组队搭配"而非堆数值。
  3. **卡牌化 UI**：立绘 + 稀有度边框 + 元素/职业图标 + 数值条；编队网格 + 协同指示；抽卡翻面动画。

**迁移到 SimVerse 的要点**
- **流派系统（Build / Synergy）**
  - *NPC 流派*：基于 `skills` / `behavior` / `big_five` 确定性派生"战士 / 学者 / 商贾 / 隐者 / 领袖"等流派标签与 build 概要（复用 `personality.go` / `npc_v3.go`，结果稳定可复现）。
  - *阵营 / 组织流派*：组织文化 = 一种流派，影响成员成长曲线与内部协同加成（扩展 `aggregates.go` / `OrgTerritory`）。
  - *玩家编队协同*：焦点 NPC 组成"队伍"，同类流派 / 区域触发自走棋式 2 / 4 / 6 羁绊加成。
- **卡牌化 UI 设计**
  - *NPC 卡片*：立绘 + 稀有度边框 + 元素/职业图标 + 数值条（借鉴卡牌收藏界面）。
  - *流派标签 chips*：在 `NPCDetail` 展示"流派 / 羁绊"标签组（与 P8 关系网呼应）。
  - *编队 / 收藏界面*：网格卡牌 + 协同指示（类似战棋编队）。
  - *关系网卡牌连线*：用卡牌 + 连线呈现 `SocialGraph`（强化 P8）。
  - *抽卡（已有 `gacha`）*：结果以卡牌翻面动画呈现，提升仪式感。

## 二、阶段规划（P9–P14）

### P9 — 智能 NPC 与情感陪伴（AI Companion）
**借鉴**：恋与深空、星穹铁道"记忆"系统
- **LLM 驱动的 NPC 对话**：基于 NPC 既有人格（`big_five`/`values`/`interests`）+ 记忆（`short_term_mem`/`life_events`）生成一致对话；端侧小模型或云端 LLM 网关两种模式。
- **记忆深化**：短期/长期记忆分层；对话反写回 `chronicle`，形成"他记得我们聊过什么"。
- **羁绊/好感系统升级**：在现有 `SocialGraph`（亲密度 `Affinity`/`LastMeet`）之上增加情感维度（信任、悸动、依赖），并支持礼物、约会、记忆回溯等互动。
- **实时陪伴**：文字气泡 +（可选）语音 TTS；NPC 主动发起对话（结合 P7 实时推送）。
- **风险/边界**：千万级 NPC 不全量接 LLM；仅对"焦点 NPC / 玩家关系网内 NPC"启用 AI，其余走确定性脚本（沿用现有 `behavior_engine`）。

### P10 — 活态世界与玩家共创（Living World + UGC）
**借鉴**：绝区零活城、七日世界动态事件、无限暖暖分享、原神尘歌壶、Roblox UGC
- **NPC 昼夜作息与职业日常**：让千万 NPC 按区域/职业产生可观测的日常流（晨市、夜巡、集会），强化"活生态"（复用 `chronicle` 事件流 + P7 实时推送）。
- **区域动态事件 + 玩家介入 2.0**：在 `WorldIntervention` 基础上，事件按区域广播，玩家可"前往现场"参与，结果回写世界。
- **UGC 叙事**：玩家创作编年史事件 / 支线剧情（模板化编辑器），审核后进入世界时间线，被其他玩家/ NPC 触发。
- **拍照/分享模式**：世界快照导出（含 NPC、区域、事件），分享卡。

### P11 — 玩家驱动经济与社交组织（Player Economy + Guilds）
**借鉴**：七日世界玩家交易/据点、MMO 公会/领地战、幻兽帕鲁基地
- **玩家间交易**：在模拟物价（`EconomyManager`）之上叠加玩家市场/拍卖行；玩家挂单影响区域供需，反哺模拟经济。
- **公会/阵营**：玩家加入组织（`OrgTerritory` 升级为可争夺领地），资源争夺、领地战（复用 `BattleManager`）。
- **声望/排行榜**：在战力榜（`battle/rank`）之外扩展组织榜、财富榜、亲密度榜（复用 `SocialStats` 聚合）。

### P12 — 赛季制与长线运营（Season / Battle Pass）
**借鉴**：米哈游标准模型（活动 + BP + 纪行）、七日世界赛季
- **赛季主题 + Battle Pass**：`QuestManager` 扩展赛季任务树与奖励轨道。
- **限时活动**：结合 P10 动态事件，运营可配置主题事件（节日、灾难、繁荣）。
- **世界演化回放 / 数据大屏**：把 `chronicle` 与 `perf` 做成可视化时间轴，玩家回看"我的世界这一赛季发生了什么"。
- **跨端同步**：移动 / PC / 云存档一致（已有 `save/load` 基础）。

### P13 — 多人共存与社交场（Multiplayer Presence）
**借鉴**：鸣潮 co-op、无限暖暖双人、各类大战场
- **同世界多玩家在线呈现**：在 Phaser 世界中加入其他玩家化身（轻量，不进千万级模拟）。
- **好友 / 组队探索**：好友关系、组队进入同一区域事件。
- **实时协作事件**：多人共同干预世界（Boss、灾害、建设）。

### P14 — 流派系统与卡牌化界面（Build/Synergy + Card UI）
**借鉴**：龙息：神寂（多重流派）、潮汐守望者 / 云顶之弈（流派协同/羁绊）、炉石（卡牌 UI）
- **NPC 流派派生**：基于技能 / 行为 / 人格确定性生成流派标签与"build 概要"，展示于 `NPCDetail`（复用 `personality.go` / `npc_v3.go`，稳定可复现）。
- **组织 / 阵营流派**：组织文化作为一种流派，影响成员成长曲线与内部协同（扩展 `aggregates.go` / `OrgTerritory`）。
- **玩家编队协同**：焦点 NPC 组成队伍，同类流派 / 区域触发自走棋式 2 / 4 / 6 羁绊加成。
- **卡牌化 UI**：NPC 卡片（立绘 / 稀有度 / 元素 / 数值条）、流派标签 chips、编队 / 收藏网格、关系网卡牌连线、抽卡卡牌翻面动画。
- **与 P9 协同**：AI NPC 的"人格"被流派强化为可辨识的"角色定位"，提升陪伴代入感；与 P8 关系网共用卡牌连线可视化。

**落地状态（2026-07-10）**：
- ✅ **NPC 流派派生（前端确定性）**：新增 `src/game/builds.ts` 的 `deriveNPCBuild(detail)`，
  基于职业 / 大五人格 / 价值观·兴趣关键词 / 财富·社会阶层 / 等级 加权打分，稳定派生
  `primary` 主流派 + 1~2 个次要 `tags` + 契合度 `synergy`(1-5)；同输入同输出，无需后端。
- ✅ **NPCDetail 卡片化展示**：新增「流派」卡片——主流派彩色徽章 + 契合度星级 + 次要流派 chips；
  i18n 新增 `simverse.build` 及 10 个 `simverse.build.<key>`（中/英）。
- ⏳ 待做：组织流派（后端 `aggregates.go`/`OrgTerritory`）、玩家编队协同（自走棋式 2/4/6 羁绊）、
  关系网卡牌连线、抽卡卡牌翻面动画、NPC 卡片稀有度边框/数值条化。

## 三、优先级建议（MVP 路径）

| 顺序 | 阶段 | 理由 |
|------|------|------|
| 1 | **P9 智能 NPC（焦点子集）** | 直接放大 P8 社交关系价值，留存杠杆最高；且只对焦点 NPC 启用，成本可控 |
| 2 | **P10 活态世界 + 拍照分享** | 复用已有 chronicle/behavior/实时推送，投入小、观感提升大 |
| 3 | **P11 玩家经济 + 组织对抗** | 把模拟底色变成"可玩社交"，但需要 P10 动态事件打底 |
| 4 | **P12 赛季/BP** | 长线运营基建，依赖前序内容供给 |
| 5 | **P13 多人共存** | 架构改动最大（需引入会话/房间），放最后 |
| 6 | **P14 流派系统 + 卡牌 UI** | 低风险的"表现层"升级，可并行于 P9/P10，立即提升所有详情/收藏界面质感与代入感 |

## 四、与现有架构的衔接点（避免重复造轮子）

- `SocialGraph`（`social.go`）→ P9 情感维度、`NPCRelations` 视图。
- `ChronicleManager` → P9 记忆回溯、P10 动态事件/UGC 时间线、P12 回放。
- `EconomyManager`（`economy.go`）→ P11 玩家市场叠加层。
- `BattleManager`（`battle.go`）→ P11 领地战、P13 协作事件。
- `QuestManager`（`quest.go`）→ P12 赛季任务树。
- `useLiveRefresh` + WS 推送（`economy:update`/`chronicle:event`）→ P9/P10 实时陪伴与事件流的基础通道。
- Phaser `WorldScene` + `NPCSprite` → P10 作息可视化、P13 多玩家化身。
- `personality.go` / `npc_v3.go`（技能/人格）→ P14 NPC 流派派生；`aggregates.go` / `OrgTerritory` → 组织流派；`SocialGraph` → P14 卡牌连线可视化；`gacha` → P14 抽卡卡牌动画。
