# Phase 4 Spec — 前端交互 + 前端性能

> **阶段目标**：打造流畅的上帝视角前端交互，优化前端性能，达到生产级体验
> **状态**：v0.1 — 规划中
> **前置依赖**：Phase 1-3（后端 + API + 优化）
> **后续阶段**：Phase 5+（内容扩展 / 多世界 / 联机等）

---

## 一、阶段目标

本阶段专注于前端体验：

1. ✅ **上帝视角交互**：观察、搜索、筛选、穿透查看
2. ✅ **分形导航**：世界 → 区域 → NPC → 脑内格系统，层级穿透
3. ✅ **事件系统 UI**：时间线、通知、事件详情
4. ✅ **前端性能**：流畅 60fps，列表滚动无卡顿，内存稳定
5. ✅ **Android 移动端适配**：触控、手势、暗黑模式、性能适配

## 二、前端架构

### 2.1 技术栈（沿用现有架构）

| 层 | 技术 | 说明 |
|----|------|------|
| 框架 | Vue 3 + Ionic 8 + Capacitor 6 | 现有移动端架构 |
| 状态管理 | Pinia | 世界状态 / NPC 数据 / UI 状态 |
| API 层 | useProxiedFetch + useWebSocket | 现有封装，支持 native 模式 |
| UI 组件 | Ionic Components + 自定义组件 | 复用现有设计系统 |
| 图表 | ECharts / Chart.js | 统计数据可视化 |
| 虚拟列表 | vue-virtual-scroller | 大量 NPC/组织列表 |
| 主题系统 | useTheme.ts | 7 色预设 + 暗黑模式 |

### 2.2 状态管理架构

```
Pinia Stores
├── useWorldStore        # 世界状态（tick/配置/统计）
├── useNPCStore          # NPC 数据缓存 + 焦点管理
├── useOrgStore          # 组织数据缓存
├── useRegionStore       # 区域数据 + 统计
├── useEventStore        # 事件流 + 通知
├── useBrainStore        # 脑内格系统数据
└── useUIPrefStore       # UI 偏好（视图/筛选/布局）
```

## 三、核心页面与交互

### 3.1 世界总览页（World Dashboard）

**功能**：
- 世界时间 / 推进速度 / 暂停-继续
- 核心指标卡片：人口 / 经济 / 组织数 / 事件数
- 实时趋势图：人口曲线 / 经济曲线 / 事件频率
- 快速入口：搜索 NPC / 组织 / 区域

**性能要求**：
- 数据更新频率：1/s（统计数据）
- 图表动画流畅：GPU 加速
- 切换响应：< 100ms

### 3.2 NPC 列表页

**功能**：
- 虚拟滚动列表（支持 10K+ 流畅滚动）
- 筛选：按区域 / 职业 / 年龄 / 性别 / 种族
- 排序：按年龄 / 财富 / 等级 / 影响力
- 搜索：姓名模糊搜索

**性能要求**：
- 滚动 FPS：60fps
- 搜索响应：< 200ms
- 筛选响应：< 300ms

### 3.3 NPC 详情页

**功能**：
- 基本信息：姓名 / 年龄 / 种族 / 性别 / 职业 / 等级
- 属性面板：六维属性 / 技能 / 资源
- 关系网：可视化关系图（家族 / 朋友 / 敌人 / 同事）
- 时间线：生命事件历史（可滑动）
- 组织身份：所属组织 / 职位 / 声望
- **进入脑内**：点击进入 NPC 大脑视图（分形 L1 层）

**性能要求**：
- 首屏加载：< 500ms（含关系网）
- 时间线滚动：60fps
- 关系图渲染：< 300ms（200 节点以内）

### 3.4 脑内视图（Brain View）

**功能**：
- 8 脑区概览：活动度 / 细胞数 / 连接数
- 脑区详情：格分布 / 类型比例 / 活动热图
- 思维模拟：记忆 / 情绪 / 决策过程可视化
- **返回上一层**：回到 NPC 详情

**交互隐喻**：
- 就像"进入 NPC 的大脑"，看到他/她的内心世界
- 不同 NPC 的脑内世界截然不同（性格不同）
- 格的活动模式对应 NPC 的行为倾向

**性能要求**：
- 脑区概览加载：< 300ms
- 热图渲染：60fps（Canvas / WebGL）
- 脑区间切换：< 200ms

### 3.5 组织列表 / 详情页

**功能**：
- 组织列表：类型筛选 / 规模排序 / 影响力
- 组织详情：成员层级 / 资源 / 关系 / 历史
- 组织关系图：同盟 / 敌对 / 贸易

### 3.6 区域地图 / 详情页

**功能**：
- 区域地图：热力图（人口 / 经济 / 事件）
- 区域详情：统计数据 / 人口结构 / 经济指标
- 区域事件：近期发生的事件

### 3.7 事件时间线页

**功能**：
- 全局事件流：按时间倒序
- 筛选：按类型 / 严重程度 / 涉及区域
- 事件详情：原因 / 结果 / 涉及的 NPC / 连锁反应
- 通知中心：重要事件推送

## 四、分形导航设计

### 4.1 层级穿透

```
世界总览
  ↓
区域地图 → 区域详情
  ↓
NPC 列表 → NPC 详情
  ↓
脑内视图 → 脑区详情
  ↓
（格系统详情 — 可选，太深了可能不需要）
```

### 4.2 交互模式

| 操作 | 方式 |
|------|------|
| 进入下一层 | 点击"进入"按钮 / 双击 / 双指张开 |
| 返回上一层 | 返回键 / 面包屑导航 / 双指捏合 |
| 同级跳转 | Tab 切换 / 侧滑 / 底部导航 |
| 快速跳转 | 搜索 / 收藏 / 历史记录 |

### 4.3 过渡动画

- 进入下一层：Zoom in + 淡入新内容
- 返回上一层：Zoom out + 淡出
- 同级切换：Slide left/right
- 所有动画 < 300ms，符合 Material Design

## 五、前端性能优化

### 5.1 渲染性能

| 优化项 | 技术 | 预期收益 |
|--------|------|---------|
| 长列表虚拟滚动 | vue-virtual-scroller | 10K+ 列表 60fps |
| 组件懒加载 | defineAsyncComponent | 首屏 +30% |
| 图片懒加载 | IntersectionObserver | 滚动 +20% |
| 数据防抖节流 | lodash debounce/throttle | 搜索/筛选减少计算 |
| Canvas 渲染关系图 | 原生 Canvas / ECharts | 500+ 节点流畅 |
| CSS 硬件加速 | transform / will-change | 动画 60fps |

### 5.2 数据层优化

| 优化项 | 技术 | 预期收益 |
|--------|------|---------|
| 数据缓存 | Pinia + localStorage | 重复访问 < 50ms |
| 增量更新 | WebSocket diff 推送 | 数据量 -80% |
| 分页加载 | infinite scroll | 首屏 < 500ms |
| 预加载 | 预测性预取 | 切换页面 < 100ms |
| 请求合并 | batch API | 请求数 -70% |

### 5.3 内存优化

| 优化项 | 技术 | 预期收益 |
|--------|------|---------|
| 虚拟列表回收 | 组件自动销毁 | 滚动内存稳定 |
| 图片回收 | 离开视口释放 | 内存 -40% |
| Store 缓存上限 | LRU + 最大条目 | 内存 -30% |
| Web Worker | 大数据计算移到 Worker | 主线程 FPS 稳定 |

### 5.4 Android 移动端专项

| 优化项 | 说明 |
|--------|------|
| 触控优化 | 10px 触控热区 / 防止误触 |
| 手势支持 | 捏合缩放 / 滑动返回 / 长按菜单 |
| 暗黑模式 | 完整适配，OLED 友好 |
| 刘海屏适配 | 安全区 / 状态栏沉浸式 |
| 键盘适配 | 输入框自动上移 |
| 性能分级 | 低端机自动降级动画 / 减少特效 |

## 六、上帝视角交互模式

### 6.1 观察模式（默认）

- 自由浏览世界
- 查看 NPC / 组织 / 区域详情
- 查看事件时间线
- 搜索和筛选

### 6.2 干预模式（可选解锁）

- 触发事件（奖励 / 惩罚 / 随机事件）
- 修改属性（需要消耗资源）
- 创建 / 摧毁实体（高权限）
- 时间控制（暂停 / 加速 / 跳转）

### 6.3 时间控制

| 控制 | 说明 |
|------|------|
| 暂停 | 世界完全停止 |
| 正常 | 1.0x 速率 |
| 快速 | 3.0x 速率（前台闲时） |
| 跳转 | 跳到指定时间，后台 catch-up |

## 七、Capacitor 移动端集成

### 7.1 前后台切换

遵循 Capacitor 架构铁律：
- **前台 → 后台**：通知后端切到 0.6x 后台模式
- **后台 → 前台**：通知后端切回 1.0x 前台模式
- **后台静置 > 5分钟**：后端自动进入 catch-up 批量推进模式

### 7.2 性能协同

- 前端 FPS < 55 → 通知后端降低推送频率
- 前端空闲 > 30s → 通知后端切到前台闲时 3.0x
- 电池 < 20% → 通知后端降频到 0.6x
- 内存告警 → 通知后端释放缓存

### 7.3 SSE 流式接口

所有流式接口严格遵守 Capacitor 铁律：
```typescript
// ✅ 正确：显式声明 Accept
fetch('/api/simverse/events/stream', {
  headers: {
    'Accept': 'text/event-stream',
  },
})
```

## 十、风险与缓解
