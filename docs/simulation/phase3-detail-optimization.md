# Phase 3 Spec — 细节补充 + 性能优化

> **阶段目标**：填充世界细节、全面性能优化、达到 Android <100MB 目标
> **状态**：v0.1 — 规划中
> **前置依赖**：Phase 1（后端核心）+ Phase 2（前后端联通）
> **后续阶段**：Phase 4（前端交互 + 前端性能）

---

## 一、阶段目标

本阶段是"量变到质变"的关键阶段：

1. ✅ **填充细节**：NPC 个性 / 组织生态 / 区域经济 / 事件系统 深度化
2. ✅ **性能优化**：内存从 ~140MB → <100MB，CPU 占用降低 30%+
3. ✅ **Android 适配**：针对移动端 CPU/GPU/内存特性做专项优化
4. ✅ **长稳验证**：30 分钟连续运行无内存泄漏、无性能退化

## 三、性能优化清单

### 3.1 内存优化（目标：140MB → <100MB）

| 优化项 | 预期收益 | 难度 | 优先级 |
|--------|---------|------|--------|
| 格数据压缩（48B → 25-30B） | -30MB | 中 | P0 |
| NPC 名字池化/字符串去重 | -5MB | 低 | P0 |
| 按需脑区加载（8个→只激活2-3个） | -50MB | 高 | P0 |
| 焦点层级缓存大小动态调整 | -10MB | 中 | P1 |
| 关系数据压缩（邻接表 → 位图+delta） | -3MB | 高 | P1 |
| 事件日志滚动 + 量化存储 | -5MB | 中 | P1 |
| 内存守卫 + OOM 时自动降级 | 稳定性 | 高 | P1 |
| GC 调优（GOGC 调整） | -10MB 碎片 | 低 | P2 |

### 3.2 CPU 优化

| 优化项 | 预期收益 | 难度 | 优先级 |
|--------|---------|------|--------|
| Catch-up 向量化 / SIMD | +30-50% | 高 | P0 |
| 批量处理（batch 1000+ NPC 一次算） | +20% | 中 | P0 |
| 事件调度器时间轮优化 | +15% | 中 | P1 |
| 随机数生成器优化（xoshiro256） | +10% | 低 | P1 |
| 热数据预加载（基于访问模式预测） | 延迟 -40% | 高 | P2 |

### 3.3 I/O 优化

| 优化项 | 预期收益 | 难度 | 优先级 |
|--------|---------|------|--------|
| ObjectBox 热数据 + SQLite 冷数据分层 | 读 +200% | 中 | P0 |
| 批量写入（攒批 + 事务） | 写 +500% | 中 | P0 |
| 异步持久化（写后缓存） | 延迟 -80% | 高 | P1 |
| 增量快照（只存变化） | 磁盘 -90% | 高 | P2 |

### 3.4 Android 专项优化

| 优化项 | 说明 | 优先级 |
|--------|------|--------|
| 后台 60% 降频 | Doze / App Standby 适配 | P0 |
| 前台/后台切换平滑过渡 | 避免切换时卡顿 | P0 |
| 温控调频 | 设备发热时自动降频 | P1 |
| 电量优化 | 低电量模式进一步降频 | P1 |
| 内存 Pressure 监听 | 内存紧张时自动降级 | P0 |
| Go runtime Android 调优 | GOGC / GOMEMLIMIT | P1 |

## 四、三级降级规范

### L1 降级（功能禁用）

| 触发条件 | 降级动作 | 用户感知 |
|---------|---------|---------|
| OOM 风险 | 释放非核心格缓存 | 部分 NPC 脑内数据加载变慢 |
| 严重温控 | 降到后台 0.6x 速率 | 世界变化变慢 |

### L2 降级（降级体验）

| 触发条件 | 降级动作 | 用户感知 |
|---------|---------|---------|
| 内存紧张 | 格模拟深度从 L3 → L2 → L1 | 脑内细节减少 |
| CPU 紧张 | 事件速率从 3x → 1x → 0.6x | 世界推进变慢 |
| 低电量 | 后台禁用格模拟 | 离开 App 时世界只推进宏观 |

### L3 降级（透明降级）

| 触发条件 | 降级动作 | 用户感知 |
|---------|---------|---------|
| 网络波动 | 本地缓存兜底 | 无感知 |
| 前端 FPS 下降 | 推送节流 | 几乎无感知 |

## 八、风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 细节爆炸导致维护困难 | 中 | 高 | 严格分形复用 + 统一抽象 |
| 内存优化后数据一致性问题 | 中 | 高 | 压缩/解压单元测试 + fuzz |
| Android 机型碎片化 | 高 | 中 | 分级适配 + 降级兜底 |
| 长稳测试暴露深层 bug | 高 | 中 | 分阶段验证 + 快速回滚 |
| 性能优化过度导致可读性下降 | 中 | 中 | 保留未优化版本作为对照 |
