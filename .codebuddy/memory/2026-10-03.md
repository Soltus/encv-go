## 1. 双端互联 spec：Iteration 19（桌面布局收尾 + 动效真 bug）

- **真 bug：`v-page-transition` 用 `from()` ⇒ 整页空白但可点击**（真实浏览器复现）
  - 现象：桌面壳 1440×900 直载 `/tabs/files`，内容区**全白**，但 `elementFromPoint(700,300)` 命中 `ion-item`
    （DOM 在、可点击、看不见）。逐时看内联样式：`transform` 从 `translate3d(0,12px,0)` 正常归零，
    **`opacity` 恒定 0**；rAF 32 tick/500ms（ticker 正常，不是卡顿）。
  - 根因：`directives/motion.ts::vPageTransition` 用 `motion.from({opacity:0})` —— `from()` 把**挂载瞬间的
    计算值当终态**，而 Ionic 转场开始前已给 `.ion-page` 写了内联 `opacity:0` ⇒ 动画实际 **0→0**。
    命中范围是带该指令的页面（`Files.vue` / `AgentChat.vue`）。
  - 修复：改 `motion.fromTo(el, {y:12*i, opacity:0}, {y:0, opacity:1, ..., clearProps:"opacity,transform"})`
    —— 终态显式写 1，与 `usePageTransition` 同款护栏。
  - 回归锁两道（均**先红后绿**）：
    ① `src/motion/__tests__/page-transition-contract.test.ts`（FAST，**源码契约锁**：必须 `fromTo`、
       终态 `opacity:1`、`clearProps` 含 opacity/transform）；
    ② `src/motion/__tests__/page-transition-directive.test.ts`（ISOLATED，功能锁：mock engine + guard）。
- **⚠️ vitest `isolate:false`（FAST 项目）的同模块 mock 污染（血的教训）**：
  - 新增任何 import `@encv/shared-components/motion/internal` 的用例，都会让 `directive-reveal.test.ts`
    的 `vi.mock(internal)` 失效 —— 实测**两个文件交替假红**（先是新用例红，改成 mock 后变成 reveal 红）。

## 2. 环境事实（沙箱内跑真实浏览器验证前端）

- 起验证链路：`go build -o /tmp/encvd ./cmd/encv` → 配置**必须是 JSON**（YAML 会报
  `invalid character 's' looking for beginning of value`）：
  `{"server":{"port":2025,"dir":"/tmp/encvd-data"},"mobile":{"server":{"dir":"/tmp/encvd-data"}}}`，
  `HOME=/tmp /tmp/encvd start -c /tmp/encvd.json`（`start` 无 `--port` flag）。
- 前端：`cd app/encv-mobile && SPAWN_VITE=1 node_modules/.bin/vite --port 8100`；
  **dev 态默认打 `:16666`（沙箱网关）**，Playwright 必须 `addInitScript` 写
  `localStorage["encv-server-url"]="http://127.0.0.1:2025"`，否则页面停在"服务器离线"兜底页。
- dev 环境噪音（非产品问题，断言要过滤）：`ws://127.0.0.1:16666` HMR 连不上 → `WebSocket closed without opened`。
