## 任务 3：Lynx 播放器重构（长期规划）

### 核心理念
主应用只是单纯入口（Tab 栏加一个播放器入口图标），所有功能都在 Lynx 页面内实现。Lynx 页面不再只是"播放器"，而是一个完整的媒体中心。

### 架构
```
主应用 (Ionic Vue)          Lynx 媒体中心
┌──────────────┐           ┌─────────────────────────┐
│ 首页 Tab     │──启动──→  │ 媒体库首页              │
│ (仅入口图标) │           │ ├─ 最近播放             │
│              │           │ ├─ 媒体分类浏览          │
│ 文件 Tab     │           │ ├─ 播放列表             │
│ 任务 Tab     │           │ └─ 设置                 │
│ 远端 Tab     │           │                         │
│ 设置 Tab     │           │ 播放页面                │
└──────────────┘           │ ├─ 视频播放 + 控件      │
                           │ ├─ 音频播放 + 歌词/频谱  │
                           │ └─ 播放列表切换          │
                           └─────────────────────────┘
```

### Phase 1：Lynx 媒体中心首页
1. Lynx 页面增加路由/视图切换（首页 ↔ 播放页 ↔ 设置页）
2. 首页：最近播放列表 + 媒体扫描入口
3. 主应用 Tab 栏添加播放器入口（仅启动 Lynx 页面）
4. Go 后端新增 API：最近播放记录、媒体扫描

### Phase 2：播放列表 + 媒体探测
1. 播放列表：当前目录自动列表、自定义列表
2. 播放器内上/下一曲切换
3. 媒体探测：扫描目录，按类型/日期分类

### Phase 3：视频边下边播
1. Go 后端 HTTP Range 流式传输（已有基础）
2. 缓冲进度条 + 预读策略
3. 离线缓存持久化

### Phase 4：音频增强
1. 歌词：LRC 解析 + 同步滚动
2. 频谱动效：Canvas 绘制
3. 后台播放：Android Service

### Phase 5：设置界面
1. 播放器设置页（画质/倍速/字幕/解码器）
2. 缓存管理
3. 均衡器
